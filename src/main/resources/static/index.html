Projeto didático · Spring Boot + Gemini

Gerador de Sínteses Integradas

Envie textos ou arquivos e receba uma única síntese em português do Brasil. A API usa apenas as informações enviadas, sem adicionar conteúdo externo.

Swagger UI OpenAPI

Entrada

Escolha como enviar o conteúdo

Digite um ou mais documentos. Eles serão combinados em uma única síntese integrada.

Endpoint: POST /api/sinteses

Total estimado: 0 palavras

Regras
  • Envie pelo menos um documento.
  • O conteúdo não pode ficar vazio.
  • Limite total: 50.000 palavras (soma de todos os documentos).

Envie arquivos para extração de texto e geração da síntese.

Endpoint: POST /api/sinteses/documentos

Nenhum arquivo selecionado.

Limites e observações
  • Formatos aceitos: .txt, .pdf, .docx.
  • Cada arquivo: até 10 MB. Requisição: até 30 MB.
  • O texto extraído de todos os arquivos pode ter até 50.000 palavras.
  • PDFs digitalizados/imagens não são suportados (sem OCR).

Saída

Síntese gerada

A síntese aparecerá aqui após o envio.

Dica: para testar a API sem interface, use o Swagger UI.
